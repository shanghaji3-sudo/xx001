# xx001
串口调试助手

基于 C# WinForms（.NET Framework 4.8）开发的 PC 端串口调试工具，用于电脑与单片机、传感器、USB 转串口模块等外设之间的串口通信调试。界面为中文，操作逻辑参考常见的友善串口调试助手。

打开串口：按当前所选参数配置 `SerialPort` 并打开，打开后状态标签变绿显示"串口已打开"。
关闭串口：释放端口，状态变红显示"串口未打开"。
打开成功后，"打开"按钮及所有参数下拉框自动禁用，防止运行中误改配置；关闭后恢复。

通过 SerialPort.DataReceived 事件异步监听串口数据。
接收文本实时追加到右侧接收框（txt_rev）。
自动滚动到最新一行（SelectionStart = TextLength + ScrollToCaret）。
使用 UTF-8 编码解码，支持中文收发。
由于事件在后台线程触发，通过 Control.Invoke 切回 UI 线程更新界面，避免跨线程异常。


下方发送框输入内容，点"发送"按钮，通过 SerialPort.Write() 发送（不自动追加换行，按原始内容发送）。
串口未打开时点击发送会弹窗提示"请先打开串口"。

清空：一键清空接收显示区。
状态指示：左下角标签实时显示串口状态（红色 = 未打开 / 绿色 = 已打开）。
异常处理：打开失败时弹窗显示具体错误信息（如端口被占用、端口不存在等）。
资源释放：关闭窗口时自动检测并关闭串口，避免 COM 口残留被占用。

命名空间：System.IO.Ports 下的 SerialPort 类。
事件驱动接收：后台监听线程触发 DataReceived，UI 线程通过 Invoke 更新控件。
窗体关闭时在 FormClosing 事件中主动 Close() 串口，保证资源正确释放。

使用方法
1. 插入 USB 转串口模块（CH340 / CP2102 等），在 Windows 设备管理器中确认 COM 口号。
2. 启动程序，在下拉框中选择对应 COM 口、波特率（须与对端设备一致）、数据位、校验位、停止位。
3. 点"打开串口"，状态变绿即连接成功。
4. 接收框实时显示对端发来的数据；发送框输入内容后点"发送"发送给对端。
5. 使用完毕点"关闭串口"，或直接关闭窗口（程序会自动释放串口）。
